# KidEmonitor Browsing Activity — Privacy Policy

_Last updated: 2026-10-22_

## What this extension does

KidEmonitor Browsing Activity is a browser extension that is part of
**KidEmonitor** (by KidEsafe), a parental-monitoring tool a parent
installs on their own child's computer. The extension watches which
website is open in the currently active, focused browser tab, and for
how long, and reports each completed visit (web address, page title, the
site's domain, start time, end time, and duration) to the **KidEmonitor
Child** application running on that same computer.

## What data is collected

For each site visited in the active tab:

- The page's full URL and domain
- The page's title
- The time the visit started and ended, and its duration
- Which browser (Chrome, Edge, or Firefox) the visit happened in

No data is collected from background/inactive tabs, from private/incognito
windows (the extension does not request incognito access), or from any
site using a scheme other than `http://`/`https://`.

## Who this data is shared with, and how

This extension sends the data above to **one place only**: a web server
run by the **KidEmonitor Child** application, on the **same computer**
the extension is installed on (`http://127.0.0.1:41237`, which is not
reachable from any other device — "127.0.0.1" always means "this same
computer," never the network). The extension does not send data to
KidEsafe, to any cloud service, or to any third party.

From there, the KidEmonitor Child application forwards the data to the
**KidEmonitor Parent** application on the household's own local home
network (Wi-Fi/LAN) — never over the public internet, never through any
server operated by KidEsafe or anyone else. The parent application stores
it locally, on the parent's own computer, for 30 days, after which it is
automatically deleted.

In short: this data stays within the household's own devices and home
network at every step. KidEsafe, as the developer of this extension,
never receives, stores, or has access to this data.

## Data retention and deletion

Visit data is kept for 30 days on the parent's computer and then deleted
automatically. A parent can remove the pairing between a child's device
and their own at any time from the KidEmonitor Parent application, which
stops any further data from being sent.
